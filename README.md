## Introduction
This repository contains the implementation for Lab 5b, a multi-page PHP and MySQL user management and authentication web application developed and tested locally using XAMPP (Apache and MySQL) and Visual Studio Code. It covers user registration, session-based login authentication, dynamic table rendering, record updates, and record deletion using prepared mysqli queries.
